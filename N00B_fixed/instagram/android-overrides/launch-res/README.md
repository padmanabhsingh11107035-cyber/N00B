Yellow NOOB launch screen for Android (colours, launch theme, logo drawables). The android/ folder is generated by CI (`npx cap add android`), so these files are kept here.
Copied in by the step "Yellow launch screen" of .github/workflows/android-build.yml (after cap add, capacitor-assets and cap sync). values/styles.xml is the Capacitor 8 template styles.xml (same style names) plus the yellow items; the step checks the generated styles first and verifies the result with grep. Proof only comes from a CI run.
