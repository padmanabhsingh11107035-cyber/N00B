# NOOB Scratch Reveal (the first standalone version)

The first, standalone version of the Scratch Reveal page, made by the NOOB developers: people post a picture sealed under scratch foil, and everybody else scratches it away.

**The version that runs inside NOOB is `N00B_fixed/instagram/src/components/Scratch/`** (real posts, reactions, notes and saves on the server; opened from the three-line menu on Home). This folder is kept as the first version, with its own sample posts, and runs on its own:

```
npm install
npm run dev
```
