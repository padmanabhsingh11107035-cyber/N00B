## Needs a human decision / left alone

- uuid 9.0.1 and gaxios 6.7.1 under `@google-cloud/storage@8.1.0` (moderate, 2 alerts). The uuid bug only matters when a caller passes its own buffer to v3/v5/v6; gaxios uses v4. Fix needs `@google-cloud/storage` 9 (major) which firebase-admin 14 does not allow. Server-side only, not reachable from users. Recommendation: wait for the next firebase-admin release; or, if the server (`server/fcm.ts`) is no longer used at all (Render was removed), delete firebase-admin from package.json and the alerts disappear.
- Dependabot only watches `/N00B_fixed/instagram` (`.github/dependabot.yml`). The nine game projects have no Dependabot entry, which is why their alerts never produced pull requests. Optional: add npm/pnpm entries for them, or delete the unused games' dev setup.
- Alerts on GitHub clear only after these files are pushed to the default branch (main); nothing was pushed.
- `latest` is used for @capacitor/core, cli, android, push-notifications and contacts in the app's package.json; the lockfile pins them, but it is a stability risk when the lock is regenerated. Suggest pinning real ranges.
- Games without a lockfile (cold-drinks, noob-run-3d, pulsegrid, scratch-reveal, siegecraft, strikebowl, terrafoundry, underhall) install a fresh vite/vitest every time, so they are not vulnerable today but are not reproducible either.
